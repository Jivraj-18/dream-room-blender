# Static Dream Room viewer

Serve this folder over HTTP or publish its contents to GitHub Pages. Open `index.html` through that server. The included GLB models, posters and Three.js modules use relative paths; no API keys or remote model services are required.

Controls: orbit/zoom/pan; room selection; walkthrough with drag-to-look and WASD/arrow keys; touch movement buttons; object inspection; side-wall visibility; GLB download.

The parent `dream_rooms/README.md` explains modeling assumptions, material differences, verification and publishing steps. Three.js 0.180.0's license is included in `vendor/THREE-LICENSE.txt`.
